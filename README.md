Token Radar ranks every pre-token DeFi protocol by the implied value of its launch and shows the board, a detail view for each protocol, and a farm plan in a static dashboard that needs no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
